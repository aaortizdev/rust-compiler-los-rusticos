# rust-compiler-los-rusticos

Analizador léxico, sintáctico y semántico para un subconjunto de Rust, hecho con PLY.

## Interfaz gráfica

**Windows:** doble clic en `iniciar_interfaz.bat`.
La primera vez crea el entorno virtual `venv/` e instala `requirements.txt`.

**Cualquier sistema operativo** (con el entorno virtual activado y `ply` instalado):

```bash
python interfaz.py
